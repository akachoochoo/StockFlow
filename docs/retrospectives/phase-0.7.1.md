## 4. 가설 검증 (ADR §2.2.5)

### 4.1 H1 (자본 활용 ≥ 48.5%) — FAIL

측정: 15.6%. 채권 ETF (214980) 의 낮은 변동성 → 5% drop 트리거 거의
미발화 → 분할 매수 누적 안 됨 → budget 50M 대부분 idle.

**가설 자체가 자산군 동질 가정** — 채권 ETF 같은 저변동성 자산에는
PriceDropStrategy 발화 빈도가 본질적으로 낮음. H1 임계 48.5% 는 자산군
다양성을 고려하지 않은 baseline (Phase 0.5 F single 19.4% × 2.5×).

### 4.2 H2 (total return ≥ +25.96%) — FAIL

측정: +5.25%. 채권 ETF 의 5-year 절대 상승폭 자체가 작음 (저변동성
자산의 본질). 069500 단독 기여분이 Phase 0.5 F (9.42%) 수준이었더라도,
214980 의 기여 미미 → 가중 평균이 단일보다 낮아짐.

**baseline 선택 자체의 한계** — Phase 0 +25.96% 는 COVID 회복 100% 흡수
특수 상황 (no-sell). 멀티 종목 + 매도 정책 환경에서는 도달 가능성 본질적
한계 — ADR §2.2.5 박제 시점 이미 인정한 trade-off.

### 4.3 H3 (Sharpe ≥ 0.39) — FAIL

측정: 0.3258. **0.39 까지 0.0642 미달** — 가장 근접한 게이트. MDD 개선
(+7.95pp) 과 return 하락 (-4.17pp) 의 상쇄 결과. Sharpe 만 보면 Phase 0.5
F 0.30 대비 +0.03 개선 — 분산 효과 확인.

### 4.4 게이트 종합 판정

0 / 3 → §2.2.5 "≥ 2 거짓 → 라운드 #5 진입" 발동. **게이트 무시 패턴
차단** (ADR §1.3) 정신 준수 — Phase 1 직진 보류 + 사용자 결정 박제 후속
(§7).

## 5. 학습

### 5.1 기술 — 무엇이 잘 작동했나

   UoW + idempotency_key 자산 unique 만으로 멀티 종목 인프라 충족. Phase
   0.5 F invariant 회귀 PASS (8 지표 완전 일치) — 리팩토링 회귀 zero.

2. **multi-asset idempotency 회귀 테스트 (commit 333251e)** — Phase 0.7.1.g
   단계에서 자산별 unique idempotency_key 박제 + 회귀 테스트 추가.
   사후적으로 Phase 0.7.1.h 백테스트 신뢰도의 안전판 역할.

3. **CSV market data loader 확장** — `--csv code=path` 형식의 멀티 종목
   주입. 백테스트 / 실거래 동일성 (CLAUDE.md §7.4) 정신 보존 — Phase 1

4. **3-way 비교 스크립트 (`scripts/analyze_phase_0_7_1.py`)** — Phase 0

   판정까지 스크립트가 출력 — 사용자 검토 부담 감소.

### 5.2 기술 — 발견 후 보강한 것

1. **자산군 분산 가설의 양면성** — MDD 개선은 명확하지만 return / 자본
   활용은 자산 특성 불일치로 하락. ADR §1.2.4 "자산군 분산 (옵션 Y)"
   채택 시 가정한 "위험 분산 + 자본 활용" 동시 달성이 정책-자산 부정합
   (§6.1) 으로 깨짐.

2. **fallback 정책 (§13.2 상관계수 < 0.5 → 후보 a 전환) 의 결과** — 사후
   분석상 채권 ETF 는 PriceDropStrategy / ProfitTargetSell 동일 정책
   (§7.3) 으로는 가설 검증에 적합하지 않은 자산. 본질적으로 §7.3 정책
   동일성 강제 vs 자산군 분산 효과의 trade-off 가 첫 시도에서 노출됨.

### 5.3 협업 — 무엇이 잘 작동했나

1. **결정 라운드 시리즈 (#1 ~ #5)** — Phase 0.7.1 동안 5 회의 사용자 명시

## 6. 발견된 이슈 / 제약

### 6.1 전략 레벨 — Phase 0.7.2+ 검토 후보

1. **정책-자산 부정합 (가장 중요한 발견)** — PriceDropStrategy (5% drop) +
   ProfitTargetSell (10% target) 는 변동성이 낮은 채권 ETF 에는 사실상
   작동 안 함. 단기채권 ETF 의 연간 변동성은 주식 ETF 의 1/10 수준. ADR
   §7.3 "종목별 동일 정책 강제" 는 인프라 검증 목적으로는 옳았으나,
   가설 검증 결과 "채권 ETF = 다른 정책 필요" 가 명확. **Phase 0.7.3 결정
   라운드의 핵심 검토 항목** (§7.3 후속).

2. **자본 배분 정책 = 균등 의 한계** — per-asset budget 50M 균등 분할은
   채권 ETF 의 낮은 활용률을 그대로 반영. 변동성 가중 / 시총 가중으로
   배분 시 채권 비중 축소 가능 — **Phase 0.7.2 핵심 비교 항목** (§4.2
   ADR 박제).

3. **종목 조합 자체의 재검토 가능성** — 채권 ETF (214980) 대신 변동성이
   더 높은 분산 자산 (e.g. KODEX 골드 132030, KODEX 배당가치 161510 등)
   으로 교체 시 자본 활용 회복 가능. **Phase 0.7.3 결정 라운드 후보**.

### 6.2 인프라 레벨 (모두 해소됨)

1. **자산별 UoW 트랜잭션 경계** — Phase 0.7.1.c 단계에서 박제 (§8.4).
   각 자산 처리는 독립 UoW — 한 자산 실패 시 다른 자산에 미영향. 회귀
   zero.

2. **idempotency_key 자산 unique** — Phase 0.7.1.g 단계에서 회귀 테스트
   추가 (commit 333251e). 같은 자산 재처리 시에만 중복 차단 — 다른 자산
   같은 날짜 처리는 허용.

3. **자산별 reconciliation** — Phase 0.7.1.c 단계에서 박제 (§8.6). 한
   자산 mismatch 시 전체 정지 정신 (CLAUDE.md §11.2) 보존. Phase 1 자산
   격리 정지 분기 가능한 구조 유지.

### 6.3 코드 레벨 (모두 해소됨)

1. **CSV market data loader `--csv code=path` 형식** — Phase 0.7.1.e 단계.
   `MarketDataPort` 구현체에서 자산별 OHLCV 분리 주입.

2. **strategies-0.7.1-F.yaml 정책 동일성 강제** — Phase 0.7.1.f. 두 자산
