## §1 Decisions

### §1.1 Phase Essence

B&H core + DGT satellite 간 주기적 리밸런싱이 정적 배분 대비 알파를
생성하는가? + 비대칭 grid(매도 spacing 확대)로 상승장 수익을 개선할 수 있는가?

### §1.2 Hypotheses

| # | Type | Statement | Threshold | Verdict |
|---|------|-----------|-----------|---------|
| H1 | PRIMARY | Drift-based rebalancing (5% threshold, 20d cooldown) ≥ 1.5% annualized alpha over static same-ratio | Net of costs | **FAIL** |
| H2 | PRIMARY | Ratio sweep (50~80%) → non-monotonic Calmar curve | Calmar peak | **FAIL** |
| H3 | INFORMATIONAL | Asymmetric grid (sell 2x spacing) + trailing stop, MDD ≤ 18% | MDD hard stop | **FAIL** (MDD 23-25% bear) |
| H4 | INFORMATIONAL | Regime switching (ADR-based) | Exploratory | Not tested |

### §1.3 Key Decisions

- **D1 (Core-Satellite architecture)**: ACCEPT — B&H core + DGT satellite with
  configurable ratio and rebalancing mode. `_HybridCoreRunner` implements.
- **D2 (Rebalancing modes)**: ACCEPT — 3 modes tested: static (no rebalance),
  drift-based (5% threshold + cooldown), calendar (every N days).
- **D3 (Asymmetric grid)**: INFORMATIONAL FAIL — wider sell spacing improves
  bull returns (+29% vs +16%) but breaks MDD guarantee (23-25% in bear).
- **D4 (Trailing stop)**: INFORMATIONAL FAIL — does not prevent drawdown.
  Only triggers after HWM decline, which is too late for bear protection.
- **D5 (Regime switching)**: NOT TESTED — H1/H2 results demonstrate that the
  fundamental question (rebalancing alpha) is answered negatively. Regime
  switching would just be a more complex way to rebalance.
- **D6 (Phase 1 recommendation)**: Static allocation, no rebalancing.
  DGT satellite = MDD defense tool only. Higher B&H ratio = higher returns.

### §3.4 Phase 1 Capital Allocation Recommendation

1. **Static allocation** (no rebalancing) — rebalancing destroys value
2. **DGT = MDD defense** — not a return enhancer
3. **Higher B&H ratio = higher returns** (monotonic, no sweet spot)
4. **Trade-off axis**: return vs MDD
   - 80% B&H / 20% DGT: max return, MDD ~12% (bull) / ~33% (bear)
   - 50% B&H / 50% DGT: lower return, MDD ~10% (bull) / ~27% (bear)
5. **If MDD tolerance > 15%**: pure B&H recommended (DGT adds friction)
6. **If MDD tolerance < 15%**: 50-60% B&H + 40-50% DGT, static
