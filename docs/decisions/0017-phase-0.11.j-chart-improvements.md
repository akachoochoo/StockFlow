### §1.4 Key Decisions (D1~D10)

#### D1 — `_grid_reconstruction.py` 신규 파일 (5th ring, underscore-private)

`src/research/dgt/_grid_reconstruction.py`. `__all__: list[str] = []` (sibling convention).

```python
def _reconstruct_grid_envelope(
    result: _DGTBacktestResult,
    config: _DGTConfig,
    mode: str,
    ohlcv_bars: list[OHLCV] | None = None,
    adaptive_cfg: _AdaptiveConfig | None = None,
    volatility_measure: str = "atr",
) -> list[list[Decimal]]:
    ...
```

Returns `[]` for `mode == "bh"` or empty snapshots. `len(return) == len(result.daily_snapshots)`. Decimal-only — `float` cast 는 JSON serialization boundary 에서만 발생 (P3).

#### D2 — Step 1b: ADR-measure branch (의도적 behaviour 변경)

`_grid_reconstruction.py` 에서 `volatility_measure == "adr"` 시 `_compute_adr` 사용, 그 외 `_compute_atr`. `_compute_adr` 는 overnight gap 무시 → 장중 범위만 반영 → 상승장에서 tighter k → 더 많은 거래 기회.

`kakao_dgt_backtest.py` 에 module-level 상수 2개 추가:
```python
adaptive_cfgs: dict[str, _AdaptiveConfig | None] = {
    "Hyb-Daily": _best_acfg,
    "ADR-Base": _best_acfg,   # Step 1b: 기존 누락 수정 (R10)
    "ADR+Vol": _best_acfg,    # Step 1b: 기존 누락 수정 (R10)
}
volatility_measures: dict[str, str] = {
    "ADR-Base": "adr",
    "ADR+Vol": "adr",
    "Hyb-Daily": "atr",
}
```

**Static chart behaviour 변경 (의도적, ADR-0017-recorded)**: `_draw_grid_levels` 가
`_reconstruct_grid_envelope` 를 통해 ADR 을 사용. `k` 가 이제 ADR-Base/ADR+Vol 에서
실제로 변동 (기존에는 `adaptive_cfgs.get("ADR-Base")` → `None` → `k` 고정).
static chart 가 더 정확해지는 것임 (의도적 개선, 회귀 아님).

#### D3 — `_serialize_grid_levels` 보존 (삭제 안 함)

`_dgt_renderer.py:301` 이 유일한 live caller. NOT dead code. 삭제 불가.
Architect M1 / Critic C1 확인. `_dgt_renderer.py` ZERO edits → backward-compatible path 영구 유지.

#### D4 — `build_interactive_chart_html` backward-compatible signature extension

ADD: `grid_groups: list[dict] | None = None` (time-varying path).
KEEP: `grid_levels: list[dict]` (static flat lines path, `_dgt_renderer.py` caller).

JS precedence: `if gridGroups non-empty → LineSeries; else if gridLevels non-empty → createPriceLine`. Data island mutual exclusivity: `grid_groups` 공급 시 `grid_levels: []` emit (§9-a).

#### D5 — `_serialize_grid_series` 신규 serializer

```python
def _serialize_grid_series(
    envelope: list[list[Decimal]],
    bar_dates: list[date],
    *,
    color: str,
) -> list[dict]:
```

`len(envelope) != len(bar_dates)` → raises (defensive). `value = float(level)` 은 P3 Decimal→float cast 유일 허용 지점. `isBound: true` for `i in (0, n)`.

#### D6 — `#grid-toggles` bar (threshold `> 1`)

`len(grid_groups) > 1` 일 때 `#grid-toggles` `<div>` render. Threshold `> 1` — single-group `_dgt_renderer.py` path 에서 toggle 불필요. JS: per-group series array; `series.applyOptions({ visible: <checked> })`. CSS: `.toggle-bar` 공통 클래스 (marker + grid toggle bars 공유).

#### D7 — Trade-log cumulative columns

`_compute_cumulative_realized_single(result)` → `dict[date, Decimal]` 재사용.
`_trade_row(t)` 에 `cum_pct: Decimal, cum_amount: Decimal` 파라미터 추가.
`<thead>` 10 columns: `... Cash Delta | Cum Realized % | Cum Realized Amount`.
Same-date collision: end-of-date 값 사용 (realized curve 시맨틱 정합; code comment 문서화).

#### D8 — v5 API mandate (ADR 0016 §3.6 root cause 반복 방지)

`chart.addSeries(LightweightCharts.LineSeries, {...})` — v5 전용.
v4 `addLineSeries` REMOVED in v5. Inline comment citing ADR 0016 §3.6.
G4 grep guard: `grep -r "addLineSeries\|addCandlestickSeries" src/research/` → empty.

#### D9 — Headless Playwright render gate (G1 — 영구 도입)

ADR 0016 §3.6 / §12.4 #6 미결 항목 **CLOSED**.
`tests/research/dgt/test_interactive_render_headless.py` 신규.
5개 assertion:
1. page errors == 0
2. canvas non-empty (픽셀 샘플링)
3. grid series visible — BOTH (i) in-page JS assert AND (ii) canvas pixel-presence (둘 다 필요 — "OR" 이면 ADR 0016 §3.6 실패 모드 통과)
4. toggle behavior (체크박스 해제 → series `visible: false` + pixel drop)
5. report.html non-truncation (~24 LineSeries × 1250 pts full load within 10s)

**Gate semantics**: `pytest.skip` (chromium 없음) == **GATE FAIL**. 이 게이트는 blessed `.venv` 에서 실행해야 함. skip == pass 는 ADR 0016 §3.6 실패 재현.

#### D10 — `bar_dates` source

`bar_dates = [s.trade_date for s in result.daily_snapshots]` (reconstruction loop 기준). `assert len(envelope) == len(bar_dates)` defensive check. `bars` (OHLCV list) 와 `daily_snapshots` 날짜 일치 (R10 / ADR 0015 §9-b 정합).

### §1.7 Named Limitations

1. **`_dgt_renderer.py` grid stays static.** No `_DGTConfig` / `mode` / `ohlcv_bars` available at that call site. `grid_history` is a single-element list (`_dgt_factory.py:68`). Follow-up #2.
2. **Volume-gate not applied to grid geometry.** Volume gate gates *trades*, not daily-mode rebalancing geometry. Follow-up #1.
3. **G1 headless gate reproducible only in blessed `.venv`.** Playwright chromium must be installed. Skip == FAIL. Follow-up #5 (Playwright in `pyproject.toml` + CI).

### §1.8 Principles

- **P1 — 5th-ring isolation.** All work in `src/research/dgt/`. Inner-ring diff = ZERO. `__all__ = []` preserved. `check_namespace.sh` exit 0.
- **P2 — Single source of truth for grid reconstruction (within `kakao` surface).** `_reconstruct_grid_envelope` is the sole reconstruction; two callers (matplotlib + interactive). No third divergent implementation.
- **P3 — Decimal discipline.** Money/price math stays `Decimal`; `Decimal→float` ONLY at JSON-serialization boundary in `_interactive_chart.py` (CLAUDE.md §2.1, ADR 0016 P4).
- **P4 — v5 API mandate.** lightweight-charts v5.2.0 API only — `chart.addSeries(LightweightCharts.LineSeries, {...})`. v4 `addLineSeries` REMOVED in v5; a v4/v5 mismatch caused the 0.11.i blank-chart bug (ADR 0016 §3.6). No v4 calls anywhere.
- **P5 — Render-truthful verification.** Structural string tests are necessary but NOT sufficient (ADR 0016 §3.6). The gate MUST include a headless Playwright render check.
