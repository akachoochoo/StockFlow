## §1 Decisions

### §1.1 Phase Essence

사용자가 daily-재중심 DGT 리포트에서 **① 그리드 가장자리 미터치 ② 평단 이하 매도**를
관찰 → 리뷰. 진단: **그리드 재중심이 그리드 트레이딩의 핵심 불변식(매도는 매수 위)을
깨뜨림.** 옵션 A(진짜 grid 복원)로 반복 개선하며 "DGT On-Breach + entry controls 가
B&H 를 이길 수 있는가" 검증.

산출: `_DGTDynamicRunner` 에 4개 **opt-in 플래그** 추가 (기본 off → 회귀 zero) +
`--strategy-set breach` CLI + 멀티에셋 인터랙티브/누적실현 버그 수정.

**스코프 경계**: `src/research/dgt/` 5th ring only. Inner ring 변경 ZERO. `pyproject.toml` 변경 ZERO. DGT lifecycle 변동 없음.

### §1.2 Load-bearing Decision: 재중심을 끄는가, 끄고 보정하는가

**진단 (코드+트레이드 로그)**: daily 재중심은 (a) 가격을 그리드 중앙에 핀 → 가장자리
도달 불가, (b) 매도 레벨을 과거 매수가 아래로 표류시켜 `holdings/(n+1)` lot-blind
슬라이스가 평단 이하로 매도. 069500 5y 에서 누적 실현 -421K 까지 하락 후 회복 못함.

| 옵션 | 설명 | 결과 |
|------|------|------|
| pure static (재중심 zero) | `_DGTPrototypeRunner` | 검증됨: 손실 매도 사라짐(+6~7%), 단 가장자리 이탈 후 휴면. 사용자 거부 ("가장자리 터치 시 갱신은 이전에 고친 동작") |
| **on_breach (돌파 시에만 재중심)** | `_DGTDynamicRunner(rebalance_mode="on_breach")` | **채택** — 사용자 의도(진짜 grid bot). 단 재중심이 손실 매도 재유발 → §1.3 가드 필요 |
| daily 재중심 유지 | 기존 | **거부** — 관찰 ①②의 원인 |

### §1.3 Key Decisions (D1~D6) — `_DGTDynamicRunner` opt-in 플래그

모두 **default off → 기존 동작·타 호출부 회귀 zero** (profit_guard=False, adaptive=None,
flat_allocation=False, max_invested_pct=None). `--strategy-set breach` 만 ON.

#### D1 — `profit_guard` (옵션 A 핵심: "매도는 매수 레벨 위에서만")
`_maybe_sell` 에서 `proceeds.rounded_price <= state.avg_cost` 면 매도 스킵. `state.avg_cost`
(가중평균 매수원가) 를 `_maybe_buy` 에서 추적 (`state.py` 에 `avg_cost` 필드 추가).
효과: 누적실현 손실 제거. **단 미실현 손실로 전환 → MDD 상승** (안 팔고 보유).

#### D2 — `adaptive` + `volatility_measure` (ADR/ATR 적응 k)
그리드 (재)생성 시점마다 `_compute_adr`/`_compute_atr` 로 `k = clamp(vol/close × mult, k_min, k_max)`.
`_grid_reconstruction.py` 의 `on_breach` 분기에도 동일 적용 (차트=러너 일치).
발견: **069500 ADR≈2% → k_max 캡(2/3/5%) 거의 안 걸림 → ADR 3종 수렴 + 고정 넓은 k 에 열위.**
멀티 10종에선 종목별 변동성 차이로 캡이 갈려 ADR 변형 분화.

#### D3 — `flat_allocation` (front-loading 제거)
`cash/(n+1)`(첫/비싼 매수가 가장 큼) → `initial_capital/(n+1)` 정액. 깊은 할인 매수 비중↑ → 평단 개선.

#### D4 — `max_invested_pct` (비중 상한 — 초반 매수 폭주 방지)
`holdings × avg_cost ≥ cap × initial_capital` 면 매수 스킵. **비용기반** 노출이라 폭락 깊어져도
추가 매수 불가 (mark-to-market 이면 가격 하락 시 노출↓로 더 사게 됨 — 회피). cap=0.75 채택
(0.60 은 V자 회복 매수 여력 과다 차단 → 단일 069500 상단 손해; 0.75 가 절충점).

#### D5 — `--strategy-set {adr,breach}` CLI
`breach` = on_breach + D1~D4(75% cap) + 6전략 sweep: 고정 k {2,3,5}% + ADR k {2,3,5}%
(multiplier 1.0, k∈[0.5%, cap]). 단일·멀티 공용. ADR variant 색상 등록 (`_colors`).

#### D6 — 멀티에셋 표시 버그 수정 (2건)
- 인터랙티브 차트: per-stock 차트가 merged(`close_price=0`) 대신 **실제 종목별 결과**(`strategy_per_stock`)
  사용 + 메인 비교 차트 멀티 시 정적 폴백 (Phase 0.11.i 이후 잠복 크래시).
- 누적실현: `_cumulative_realized_by_date` 신규 — merged 트레이드에 단일 평단 회계 적용하던
  혼합 평단 버그 (한국전력 2만/LG화학 30만 혼합 → 가짜 음수 1471행) → 종목별 합산 → 0행.

추가: `_build_asset` KRX ticker-name 로그인 게이트 실패 시 code 폴백 (외부 이슈 우회).

#### §3.2 G2 — REGIME-SPLIT (핵심 발견)

**5y (2020-2024, COVID 폭락+횡보 포함):**
- 단일 069500: On-Breach-5%+가드 +19.31% (cap 없이 D만) / cap75 +15.68%, MDD -22.9% vs B&H +21.10%/-34.58%.
  단일·V자 회복에선 cap 이 5% 상단을 깎음 → Calmar 캡없음(0.149)>75%(0.132)>60%(0.095).
- **멀티 10종 + D+B(75%): On-Breach-5% +15.19% / MDD -24.08% / Sharpe 0.292 / Calmar 0.122
  vs B&H +15.90% / -36.71% / 0.247 / 0.084 → 처음으로 DGT 가 B&H 를 Sharpe·Calmar·MDD 로 상회.**
  분산 바스켓엔 V자 미회복 종목(NAVER/LG화학/셀트리온) 이 섞여 cap/정액배분이 도움 (단일과 정반대).

**1y (2025-05-21 ~ 2026-05-21, 강세장):**
- 멀티 10종: DGT +30~38% / MDD -12~13% / Sharpe 1.6-1.9 **vs B&H +185.88% / -23.01% / 3.03**.
  → **B&H 모든 지표 압승.** 그리드가 상승분 조기 매도 → 추세장 구조적 패배 (ADR 0014 G2 FAIL 정합).

**판정 근거**: G2 는 국면 의존. 강세장 = FAIL (구조적), 횡보/폭락+분산 = 위험조정 PASS.
→ ADR 0007 D10 archive / ADR 0014 "DGT = MDD 방어 전용" 결론을 **메커니즘 수준에서 재확인.**

### §1.5 Risks + Named Limitations

| ID | 항목 | 처리 |
|----|------|------|
| R1 | profit_guard = 손절 아님 (보유로 MDD 상승) | 명시 한계. 하락장 방어엔 별도 강제청산 필요 (미적용) |
| R2 | ADR 적응 k 가 저변동 단일종목(069500)에서 캡 미작동 → 고정 k 열위 | 발견 박제. multiplier 스윕 미탐색 (follow-up) |
| R3 | cap 값(0.75) = 단일/멀티 trade-off 산물, 단일 hardcode | 튜닝 가능; CLI 노출 미구현 (follow-up) |
| R4 | 멀티 인터랙티브 리포트 대용량 (6전략×10종 ~77MB) | `reports/` gitignore; 정적/전략축소 옵션 존재 |
| R5 | G2 강세장 FAIL = DGT 구조적 한계 | 본질 — 완화 불가. Phase 1 권고로 흡수 |

**Named Limitations**: ① ADR k 가 069500 같은 저변동 자산에서 사실상 무력. ② cap 단일종목 V자에선
역효과. ③ 추세 매수 게이트(slope gate)·시간 단계적 해제는 미적용 (다음 후보). ④ 정본 박제가
사후 작성 — 게이트 사전 정의 없이 진행됨 (본 ADR 이 1차 박제).

### §1.6 Principles
- **P1 — 5th-ring isolation**: 모든 변경 `src/research/dgt/`, inner ring diff 0, `check_namespace.sh` exit 0.
- **P2 — Opt-in default-off**: 신규 플래그 4종 모두 기본 off → 기존 runner 사용처 회귀 zero.
- **P3 — Decimal discipline**: avg_cost/cap 산술 Decimal; float cast 는 JSON 경계만.
- **P4 — 정직한 국면 보고**: G2 를 단일 PASS/FAIL 로 강제하지 않고 국면별 분리 보고.
