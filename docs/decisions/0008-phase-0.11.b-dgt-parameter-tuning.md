- **D10** — Computation budget — **수치 추정** (Round 1 ITERATE Patch 9):

  D4 축소 (3+1 차원) 기준 grid 탐색점 = n[3,5,7,9,11] × k[2,3,5,7,10] × m[1,2,3,4] = 5 × 5 × 4 = **100 점**. WFO 5-fold = **500 runs**. 단일 run 0.13s (0.11.a R6) → **65s** (R3 60s bound 미세 초과).

  **Mitigation — coarse-to-fine 2-pass**:
  1. 1st pass: coarse grid 100 점 × WFO 5-fold = 65s. Top-10 parameter set 식별.
  2. 2nd pass: top-10 fine search 20 점 × WFO 5-fold = ~13s. + re-anchor period 변동 20 점 = ~13s.
  3. 총 ~91s ≤ **100s bound** (R6 60s 의 ~1.7배 — 명시 허용).

  PBO / WRC optional 계산은 추가 budget = +30s (1000 trial bootstrap). 총 worst case ~120s.

  **Bound**: 총 실행 시간 ≤ 120s (R6 60s 의 2배), 메모리 ≤ 200MB (R6 36.78MB 의 5.4배). 초과 시 D10 trigger — early stopping.
- **D11** — D10 archive 재검토 trigger 의 정량 기준 — **AND-gate 재정의** (Round 1 ITERATE Patch 2, lucky-parameter loophole 차단):

  > **D11 trigger (AND-gate)**: G2 PASS 조건 = 다음 *모두* 충족:
  > - **(a)** OOS window 에서 4 지표 *모두* Phase 0.7.3 baseline 대비 악화폭 ≤ 10%:
  >   - CAGR ≥ 2.32% (baseline 2.5779 × 0.9)
  >   - MDD ≥ -9.10% (baseline -8.2737 × 1.10)
  >   - OOS Sharpe ≥ 0.473 (baseline 0.5255 × 0.9) — (a) 의 Sharpe 슬라이스가 OOS 임을 명시
  >   - Calmar ≥ 0.280 (baseline 0.3116 × 0.9)
  > - **(b)** Deflated Sharpe Ratio ≥ 1.0 (95% 신뢰 수준, Bailey & Lopez de Prado 2014)
  > - **(c)** Parameter perturbation ±10% 에서 worst OOS Sharpe > 0.3

  > **Round 2 정리** (Architect/Critic NON-BLOCKING): 원 Round 1 권고 (c) "OOS Sharpe ≥ baseline × 0.9 = 0.473" 는 (a) 의 Sharpe 슬라이스와 산술 동일 → 삭제 (사용자 결정 2026-05-12). (a) 에 "OOS" 명시 강화로 의도 보존. 기존 (d) perturbation 은 (c) 로 renumber.

  **불충족 시**: G2 = INFORMATIONAL 강등 (0.11.a G2 패턴), D10 = archive 확정, best parameter set + OOS 결과 informational 박제 → Phase 1 ADR 0012 진입 시 일봉 한계의 정량 근거로 활용 (archive 가치 보존).

  **거부된 default** ("3/4 + DSR > 0 + OOS 0.3") 사유 5 결함:
  1. 3/4 = MDD 무시 가능 (CAGR / Sharpe / Calmar 강한 상관, MDD 만 FAIL 이어도 통과 — correlation blind spot)
  2. DSR > 0 = random strategy 통과 가능 (Bailey & Lopez de Prado 유의 임계 DSR ≥ 1.0)
  3. OOS Sharpe 0.3 < baseline 0.5255 (43% 하락 허용 ≠ "baseline 회복")
  4. Perturbation robustness 미포함
  5. AND / OR 혼합 구조 모호 (G2 CONDITIONAL PRIMARY 의 의미 모호)
- **D12** — Reproducibility: 0.11.a AC15 (byte-identical 2회 실행) invariant 보존 + 추가로 (a) random seed 박제, (b) parameter search 의 deterministic ordering. D3 (b) Optuna TPE 거부와 정합 — grid + WFO 의 deterministic 순서 보장.

### 1.5 Risks (R1~Rn, ralplan #24 박제 대상)

- **R1 (HIGH)** — **Overfitting**. 파라미터 공간이 **3+1 차원** (D4 축소) + 탐색점 100 ~ 120 (D10) → in-sample 만 좋고 OOS FAIL 위험. **Mitigation**: D8 가드레일 (DSR ≥ 1.0 / purge gap ≥ 5 days / perturbation ±10% worst Sharpe > 0.3) + **0.11.b.4 산출에 DSR 수치 + perturbation worst Sharpe + optional PBO 확률 + optional WRC p-value 표 박제 의무** (Round 1 ITERATE Patch 10, 0.11.a comparison 패턴). G2 판정 근거의 감사 추적성 확보.
- **R2 (HIGH)** — **D10 archive 결정의 prematurely supersede 위험**. 본 phase 가 lucky parameter set 하나로 G2 PASS 를 만들어도 본질적 R1 (일봉≠분봉) 은 미해결. Mitigation: D11 trigger 를 "단일 metric 회복" 이 아닌 "OOS + DSR + perturbation robustness" 의 합으로 정의.
- **R3 (MEDIUM)** — **Computation budget overrun**. WFO + grid + Bayesian 병행 시 R6 bound (60s, 1GB) 초과 가능. Mitigation: D10 에서 사전 추정 + early stopping.
- **R4 (MEDIUM)** — **Diagnostics 부재로 0.11.a §8 한계 재현**. B2 보완을 D2 에서 회피 시 본 phase 회고도 "튜닝 결과만 있고 왜인지 모름" 패턴 반복. Mitigation: D2 (a) 또는 (b) 강제, 0.11.c 의존성 미허용.
- **R5 (MEDIUM)** — **Baseline fairness 미흡**. 069500 단독 buy-and-hold 빠지면 "DGT vs Phase 0.7.3" 비교가 자산 1차원 차이를 또 흡수. Mitigation: D7 의 (ii) 필수.
- **R6 (LOW)** — **Namespace pollution**. `src/research/dgt/optimization/` 가 0.11.c visualization 과 cross-import 위험. Mitigation: D9 에서 격리 + `scripts/check_namespace.sh` 확장.
- **R7 (LOW)** — **Random seed drift**. parameter search 의 비결정성 → AC15 reproducibility 위반. Mitigation: D12.

### 1.6 Namespace Discipline

ADR 0007 §1.6 5-ring 격리 패턴 **그대로 상속**. 본 phase 의 코드는 `src/research/dgt/optimization/` (D9 default) 에 위치하며 production rings (domain / application / adapters / use_cases / cli / infrastructure / ports) 변경 zero. `scripts/check_namespace.sh` 7-ring grep 통과 invariant 보존 + **intra-research cross-import 차단 grep rule 신규 추가** (D9 박제, 0.11.b.2 sub-step 산출 — `src/research/dgt/*` 가 `src/research/{visualization, …}/*` 을 import 하지 않음을 grep 으로 강제).

- 발생: D11 AND-gate 통과한 parameter set 이 6 개월 후 regime change (변동성 급증 / 추세 전환) 에서 OOS 외 데이터 collapse.

**시나리오 B — Computation 60s bound 초과**:
- 발생: D4 축소 후에도 (i) ~ (iv) 4 차원 + WFO 5-fold = 500 runs × 0.13s = 65s > R6 60s bound.
- 원인: 단일-run 시간 0.13s 가정 (0.11.a R6) 이 OOS 분할 시 cache miss / I/O 증가로 0.2s+ 로 증가 가능.
- Mitigation: D10 coarse-to-fine 2-pass + early stopping (top-K 식별 후 fine 탐색) + 100s ~ 120s bound 명시 (R6 60s 의 1.7 ~ 2배 허용).

**시나리오 C — D11 strict → G2 FAIL → Phase 1 진입 지연**:
- 발생: D11 AND-gate 채택 후 일봉 한계 (0.11.a R1) 로 G2 FAIL → 0.11.b archive 확정 → 사용자 "왜 0.11.b 했냐?" 의문.
- 원인: 일봉 환경에서 grid trading 의 본질적 한계 — intraday oscillation 정보 부재.
- Mitigation: G2 FAIL graceful degradation — INFORMATIONAL 강등 + best parameter set + DSR / perturbation 수치 박제 → Phase 1 ADR 0012 분봉 DGT 검토 시 정량 근거 활용 (archive 가치 보존). 사용자 명시 "튜닝 결과가 좋으면 promote 재고" 의 *대칭 case* (튜닝 후에도 archive 라면 archive 사유의 정량 박제).
