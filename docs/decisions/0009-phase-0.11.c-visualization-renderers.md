## 1. Decision Drivers (ralplan #25 라운드 1 박제 대상)

### 1.1 사용자 spec verbatim

> "백테스트 하고 전 기간에 걸쳐서 매수 매도 한 시점 그리고 그리드 상단 하단, 누적 수익, 등을 표시하고 전략 마다 비교해보고 싶은데 가능할까? 이 경우 전략마다 렌더러가 따로 존재 해야 할것 같은데"
>
> **사용자 직관 박제**: 전략별 렌더러 분리 = 정확한 설계 방향. ralplan #25 에서 anti-pattern (단일 거대 렌더러) 거부 정당화 필요.

### 1.2 도메인 분석 — 왜 strategy-specific 렌더러가 필요한가

| 전략 | 공통 요소 | 전략-specific 요소 |
| --- | --- | --- |
| Buy-and-Hold | 가격 곡선 + 매수 시점 + 누적 수익 + drawdown | (없음) |
| 세븐 스플릿 | 동상 | 분할 매수 가격 라인 (7개) + 각 split 의 매도 시점 + 잔여 split 수 + split 별 P&L |
| DGT (Phase 0.11.a/b) | 동상 | 시간 가변 grid 상단/하단 envelope + reference price 곡선 + grid level 별 trade marker |
| (후속) Score-based | 동상 | 종목 score 히트맵 + 리밸런싱 시점 |
| (후속) 부동산 분산 | 동상 | 자산군별 weight stack plot |

→ 공통 요소는 strategy-agnostic, 전략-specific 요소는 전략 도메인 지식 의존. 단일 렌더러로 합치면 (a) cyclomatic complexity 폭발, (b) 새 전략 추가 시 기존 코드 수정 (OCP 위반), (c) test 매트릭스 곱셈.

### 1.5 Risks (R1~Rn, ralplan #25 박제 대상)

- **R1 (RESOLVED)** — **Namespace 결정**. D1 = (a) `src/research/visualization/` (사용자 결정 2026-05-12). Intra-research cross-import 정방향 허용 (D9) + 역방향 차단 (ADR 0008 D9 grep rule 상속). Import cycle risk 해소.
- **R2 (HIGH)** — **`BacktestResult` 스키마 도메인 / application 침범**. D3 에서 전략별 metadata 를 `src/application/backtest_runner.py:67-155` frozen dataclass 에 넣으면 0.10.bb 박제 invariant + 0.11.x "production rings 변경 zero" 양쪽 위반. **Mitigation (Round 1 ITERATE Patch 2 구체화)**: 2 가지 concrete 패턴 — (A) `TradeView.annotations` enrichment (application layer, ADR 0006 §16.3 `_enrich_with_slot_number` patten `trade_view.py:116-145` 재사용); (B) `src/research/visualization/` sidecar dataclass (`DGTVisualizationArtifacts`, 5th ring 내부). 두 패턴 병행 — episode-scope marker = (A), full-period DGT-specific overlay = (B). `BacktestResult` 필드 추가 zero.
- **R3 (LOW — downgrade)** — **Backend lock-in**. D4 (a) matplotlib only 채택 → Plotly 사후 요청 발생 시 follow-up phase 위임. ADR 0008 D2 패턴 정합 (simplicity 우선). Mitigation: §1.10 시나리오 C (Plotly 사후 요청) graceful path 박제.
- **R4 (LOW)** — **Visual regression test false positive**. D10 (i) PNG byte-identical 거부 + (ii) figure metadata snapshot 채택. Mitigation: G4 의 figure metadata snapshot 2회 byte-identical 검증 + dimension/DPI 고정.
- **R5 (LOW)** — **0.11.b 와의 산출 중복 + intra-research cross-import 방향성**. ADR 0008 §1.8 sub-step 0.11.b.3 의 sensitivity heatmap 은 ADR 0008 D2 = Markdown only PNG 차단 → 본 phase 0.11.c 가 PNG 흡수 (D5 충돌 해소). Mitigation (Round 1 ITERATE Patch 9): D9 정방향 / 역방향 명시 — `src/research/visualization/` → `src/research/dgt/` 정방향 허용 (outer→inner read), `src/research/dgt/` → `src/research/visualization/` 역방향 차단 (ADR 0008 D9 grep rule). `scripts/check_namespace.sh` 정방향 허용 rule 추가 의무.
- **R6 (LOW)** — **한국어 폰트 환경 의존**. matplotlib 의 CJK font 부재 시 한글 깨짐. **Mitigation (Round 1 ITERATE Patch 12)**: `src/adapters/reporting/chart.py:155-163` 의 `_cjk_candidates` tuple + `FontProperties` per-Text override 패턴 그대로 재사용.
