### 1.6 § Namespace Discipline (Architect (i) + (ii) + Critic Major #1)

#### 1.6.1 5th ring 정의

`src/research/` 는 Clean Architecture 의 **5th (outermost) ring**.

```
[src/research/]  ← 5th ring (outermost, 본 ADR 신규)
       ↓ outer→inner read OK
[src/cli/, src/adapters/, src/infrastructure/]  ← Frameworks ring
       ↓
[src/application/, src/use_cases/]  ← Use Cases ring
       ↓
[src/ports/]  ← Ports ring
       ↓
[src/domain/]  ← Domain ring (innermost)
```

규칙:
- `src/research/dgt/*.py` 는 **inner ring 읽기 OK** (`from src.domain.models import Asset`, `Asset.round_to_tick` 호출 가능 = Architect (ii) "outer→inner read OK (ring direction)" 정정 흡수).
- `src/{adapters,application,cli,domain,infrastructure,ports,use_cases}/*.py` 에서 **`from src.research.*` import FORBIDDEN** (Architect Nudge 1 = 7-ring grep target).
- `python -m src.research.dgt.cli` 진입은 ring boundary 위반 아님 (`python -m` semantics — CLI 는 outer terminal 진입점).

#### 1.6.2 CI Enforcement (D11 plain grep 채택)

`scripts/check_namespace.sh` (sub-step 0.11.a.2 산출, AC13 oracle):

```bash
#!/usr/bin/env bash
# Phase 0.11.a § Namespace Discipline enforcement (D11 plain grep)
# Fails if any inner ring imports from src.research.
set -euo pipefail

INNER_RINGS=(
  "src/adapters"
  "src/application"
  "src/cli"
  "src/domain"
  "src/infrastructure"
  "src/ports"
  "src/use_cases"
)

violations=0
for ring in "${INNER_RINGS[@]}"; do
  if [ -d "$ring" ]; then
    if grep -rE "^[[:space:]]*from src\.research|^[[:space:]]*import src\.research" "$ring" 2>/dev/null; then
      echo "FAIL: $ring imports from src.research"
      violations=$((violations + 1))
    fi
  fi
done

if [ "$violations" -gt 0 ]; then
  exit 1
fi
echo "OK: namespace discipline preserved (7-ring grep)"
```

**Critic Major #1 흡수**: 7-ring 전부 명시 (adapters/application/cli/domain/infrastructure/ports/use_cases). Round 2 plan 의 5-ring 누락 정정.

**D11 = plain grep 채택 이유**: import-linter dev dep 추가 = CLAUDE.md §0 새 의존성 사용자 승인 trigger. plain grep 으로 dep 추가 zero + AC13 충분 enforce.

### 1.10 Acceptance Criteria (AC1~AC15, oracle 명시)

#### AC1: `KoreanMarketCostModel.compute_buy_cost` Decimal 정확성

```python
# tests/research/test_cost_model.py
cost_model = KoreanMarketCostModel()
result = cost_model.compute_buy_cost(
    price=Decimal("100000"),
    quantity=Decimal("10"),
    asset=Asset.kr_etf("069500"),
)
# 거래세 = 0 (매수)
# 위탁수수료 = 1_000_000 * 0.00015 = 150
# 총비용 = 1_000_000 + 150 = 1_000_150
assert abs(result.total_cost - Decimal("1000150")) < Decimal("0.0001")
assert result.tax == Decimal("0")
assert abs(result.commission - Decimal("150")) < Decimal("0.0001")
```

#### AC2: `compute_sell_cost` 거래세 적용 (KR_ETF)

```python
result = cost_model.compute_sell_cost(
    price=Decimal("100000"),
    quantity=Decimal("10"),
    asset=Asset.kr_etf("069500"),
```
