```python
listed_at: date  # 상장일 — 5-year 백테스트 가용성 검증 + tradeable 판정
delisted_at: date | None = None  # 상장 폐지일 (Phase 0.9 미사용, Phase 1+ 미래 대비)

def is_tradeable(self, as_of: date) -> bool:
    """거래 가능 여부 (상장일 ≤ as_of < 폐지일)."""
    if as_of < self.listed_at:
        return False
    if self.delisted_at is not None and as_of >= self.delisted_at:
        return False
    return True
```

```python
# src/domain/tick_size.py 신규
def calculate_krx_stock_tick_size(price: Decimal) -> Decimal:
    """KRX 개별 주식 호가 단위 (가격대별).

    KRX 호가 단위 (2023~ 기준):
        < 1,000원       : 1원
        < 5,000원       : 5원
        < 10,000원      : 10원
        < 50,000원      : 50원
        < 100,000원     : 100원
        < 500,000원     : 500원
        ≥ 500,000원     : 1,000원

    ETF 는 본 helper 미사용 (Asset.tick_size 단일값 = 5원 KOSPI ETF
    표준).
    """
    if price < Decimal("1000"):
        return Decimal("1")
    elif price < Decimal("5000"):
        return Decimal("5")
    elif price < Decimal("10000"):
        return Decimal("10")
    elif price < Decimal("50000"):
        return Decimal("50")
    elif price < Decimal("100000"):
        return Decimal("100")
    elif price < Decimal("500000"):
        return Decimal("500")
    else:
        return Decimal("1000")
```

`Asset.round_to_tick(price)` 변경 (asset_class 분기):

- `KR_STOCK`: `calculate_krx_stock_tick_size(price)` 호출 후 round

| **A) 합병 (0.9.d + 0.9.f → 0.9.d)** | **채택** | placeholder 의사결정 회피 + 차원 분리 합리성 약함 + 회귀 invariant 위험 zero + commit 양 적절 + 0.9.h~0.9.i 시점 helper 도입 보장 |

#### 3.3.1 합병 근거 상세

**근거 1: placeholder 의사결정 회피**

0.9.d 분리 시: KR_STOCK factory 의 `tick_size: Decimal` 필드를 어떤
값으로 채울지 결정 필요 (예: `Decimal("100")` 가격대 reasonable vs
`Decimal("1")` 보수적). 이 값은 0.9.f helper 도입 후 KR_STOCK 분기에서
무시되어 **dead code 결정** 이 됨. 합병 시: helper 가 도입되어
`Asset.tick_size` 필드는 KR_ETF 만 사용, KR_STOCK 은 helper 동적 호출
→ placeholder 자체가 불필요.

**근거 2: 차원 분리 합리성 약함**

ADR 0005 §1.12 의 sub-step 분리 패턴은 Phase 0.7 (정책 차원 / 종목 차원
분리) 일관 — 단 0.9.d 와 0.9.f 는 둘 다 **Asset 모델의 KR_STOCK 지원**

#### 6.5.1 trade-off 패턴 — 변경 차원 무관

Phase 0.8.1 (전략 차원 변경 — SupportLevel) 과 Phase 0.9.1 (종목 차원
변경 — 개별 주식) 모두 **동일한 trade-off 패턴** 발현:

> **트리거 빈도 ↑ + return 절대값 ↑ vs MDD 큰 폭 ↑ + Sharpe ↓**

ADR 0004 §7 박제 ("PriceDropStrategy + 분산이 본질") 검증 결과:
- **PriceDropStrategy 자체** 가 변하지 않아도 (Phase 0.9.1) H3 미달 가능
- **분산 약화** 가 H3 미달의 충분 조건임 — Phase 0.8.1 (whipsaw
  trigger ↑ → MDD ↑) + Phase 0.9.1 (자산군 동조성 ↑ → MDD ↑) 두 경로
  동일 결과

→ ADR 0005 §1.2.3 박제 예측 시나리오 C ("Phase 0.8.1 패턴 반복, H3
본질적 한계 인정") 의 본질이 **분산 효과 약화** 임이 데이터로 확인됨.
