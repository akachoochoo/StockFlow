#### 1.7.2 listed_at / delisted_at 추가 (5.2 = A)

```python
listed_at: date  # 상장일 — 5-year 백테스트 가용성 검증 + tradeable 판정
delisted_at: date | None = None  # 상장 폐지일 (Phase 0.9 미사용, Phase 1+ 미래 대비)

def is_tradeable(self, as_of: date) -> bool:
    """거래 가능 여부 (상장일 ≤ as_of < 폐지일)."""
    if as_of < self.listed_at:
        return False
    if self.delisted_at is not None and as_of >= self.delisted_at:
        return False
    return True
```

```python
# src/domain/tick_size.py 신규
def calculate_krx_stock_tick_size(price: Decimal) -> Decimal:
    """KRX 개별 주식 호가 단위 (가격대별).

    KRX 호가 단위 (2023~ 기준):
        < 1,000원       : 1원
        < 5,000원       : 5원
        < 10,000원      : 10원
        < 50,000원      : 50원
        < 100,000원     : 100원
        < 500,000원     : 500원
        ≥ 500,000원     : 1,000원

    ETF 는 본 helper 미사용 (Asset.tick_size 단일값 = 5원 KOSPI ETF
    표준).
    """
    if price < Decimal("1000"):
        return Decimal("1")
    elif price < Decimal("5000"):
        return Decimal("5")
    elif price < Decimal("10000"):
        return Decimal("10")
    elif price < Decimal("50000"):
        return Decimal("50")
    elif price < Decimal("100000"):
        return Decimal("100")
    elif price < Decimal("500000"):
        return Decimal("500")
    else:
        return Decimal("1000")
```

`Asset.round_to_tick(price)` 변경 (asset_class 분기):
- `KR_ETF`: 기존 단일 `tick_size` 사용 (회귀 invariant 보존)
- `KR_STOCK`: `calculate_krx_stock_tick_size(price)` 호출 후 round
