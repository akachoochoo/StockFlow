### 1.3 본 phase 의 비범한 위험성 (다른 phase 와 다른 점)

본 phase 는 0.11.b/c/d 와 본질이 다름 — **multi-asset-trading-system-design §1.3 "AI 일단위 파라미터 튜닝 거부" invariant 와 정면 충돌 가능 영역에 박제**. 따라서 §1.6 의 design contract 가 다른 phase 의 invariant 보존보다 더 strict.

핵심 risk 2 개 (§1.5 R1+R2 정밀화):

1. **Reflexive overfitting** — 시스템이 자기 거래 결과 보고 파라미터 변경 → 1000 거래 미만 단계에서 noise 적합. multi-asset-trading-system-design §1.2 "샘플 부족 (연 250 데이터 포인트 미만)" 정면 적용.
2. **결정 누락 cascading** — L2 변경 → 새 baseline → 다음 L2 변경 → ... → 6개월 후 추적 불가. CLAUDE.md §7.1 "결정 시점 입력값 전체를 JSON 보존" invariant 의 *발굴/조정 단계 확장* 의무.

- **D1** — **L2/L3 trigger 신호 정의 — 원천 데이터 제약 hard + AND-gate + sample size threshold + NULL proposal** (Round 1 ITERATE Patch 4):

  **원천 데이터 제약 hard**: L2/L3 trigger evaluator 입력 = **backtest OOS metric + 확정 OHLCV 데이터 only**. 실시간 가격 / VIX / 뉴스 / sentiment / 소셜 미디어 신호 = **절대 금지** (L1 Phase 2 영역). Enforcement: `scripts/check_namespace.sh` 확장 또는 별도 grep rule (`grep -rE "(실시간|VIX|뉴스|sentiment|twitter)" src/research/dynamic_adjustment/` empty).

  **Trigger 후보**:
  - (i) **Rolling OOS Sharpe 임계** (예: 36-month rolling Sharpe < 0.3, backtest 통계 기반) — **AND-gate 조건**: (a) sample size ≥ 100 거래 + (b) Drawdown 임계 동시 충족.
  - (ii) **Drawdown 임계** (MDD < ADR 0007 §3 G2 baseline × 1.50 = -50% 악화 한계, backtest 통계 기반) — **drawdown trigger ≠ 손절 제안** (Round 1 ITERATE Patch 7, CLAUDE.md §11.4 정합): trigger 발화 = "전략 재검토 제안" 생성. 손절 / 포지션 축소 제안 = Phase 1 ADR 0012 별도 영역. `ProposalType` enum 에 `STOP_LOSS` 부재 명시.
  - (iii) **Regime change 감지** (자산 변동성 24-month 평균의 2배) — **거부 (Phase 2 위임)** (Round 1 ITERATE Patch 12). 거부 사유: regime change = 실시간 변동성 신호 의존 → D1 원천 데이터 제약 (backtest OOS only) 위반 + §1.6 #2 invariant 충돌. L1 (실시간 차단기, Phase 2) 의 정확한 책임 영역.
  - (iv) **사람 ad-hoc 요청** — CLI command 진입.

  **권고 default**: **(i) AND (ii) AND (iv) 조합 AND-gate** (ADR 0008 D11 패턴 정합) + (iii) 거부 박제.

  **NULL proposal semantics**: trigger 발화 but sample size < 100 또는 AND-gate 조건 미충족 시 "데이터 부족으로 평가 보류" NULL proposal 생성 (Architect 권고 #1 흡수 — 자동 제안 차단 + 추적성 보존).
