## §1 Decisions

### §1.1 Phase Essence

DGT 백테스트 리포트의 모든 chart surface 를 **interactive lightweight-charts** 로 전환.
사용자가 실제 검토하는 `report.html` 과 `_dgt_renderer.py` full-period renderer 는
**100% interactive** (zoom / pan / hover). Phase 0.11.h static matplotlib renderer 는
**보존, thin** — retrospective figure 박제 재현용 archival-only path 로 강등.

**스코프 경계**: visualization tooling 변경만. 전략 재검증 / inner ring 변경 / pyproject.toml
변경 없음. Production `src/adapters/reporting/` HTML 은 미변경 — reversal 은 5th ring
research report surface 에만 적용.

### §1.3 Key Decisions (D1~D9)

#### D1 — Library = lightweight-charts (TradingView JS), NOT Plotly

**결정**: TradingView `lightweight-charts` v5.x (vendored standalone JS, ~50 KB).

**이유**: Option A (`lightweight-charts-python` PyPI wrapper) — desktop/Jupyter 지향,
`pywebview` GUI 의존성, embeddable report HTML 로 사용 불가 → **거부**.
Option C (CDN `<script src>`) — offline 재현 불가 (P5 위반) → **거부**.
Option B (vendored JS in `src/research/dgt/assets/`) — offline self-contained (P5),
zero blast radius on Python trading system (P2/DD1), pinned version + SHA-256
provenance → **채택**.

#### D2 — Containment: Vendored JS is a new external dependency (CLAUDE.md §0)

vendored `.js` 는 새 외부 의존성 (CLAUDE.md §0 "새 외부 의존성 = 사용자 승인 필요").
사용자의 explicit interactive-charts 승인이 이를 충족.
**Blast radius zero**: JS 는 browser 가 `report.html` 을 열 때만 실행 — Python 거래
프로세스 / cron path / domain layer 에 전혀 영향 없음. pyproject.toml 변경 zero.

#### D3 — Module location: `src/research/dgt/` (intra-research cross-import rule)

`_interactive_chart.py` + `assets/` 는 `src/research/dgt/` 에 위치.

이유: `kakao_dgt_backtest.py` (dgt 내) 가 intra-dgt import (legal).
`_dgt_renderer.py` (visualization 내) 는 `visualization → dgt` forward direction
(allowed by `scripts/check_namespace.sh:58-68`) 으로 import. `dgt → visualization`
reverse 는 FORBIDDEN — C1 relocation 이 이 invariant 보존.

#### D4 — Protocol: Option (iii) `fmt` defaulted kwarg

`_VisualizationRenderer.render_full_period(bars, trades, artifacts=None, *,
fmt: Literal["png","html"] = "png") -> bytes | str`.

Option (i) Protocol mutation (`-> HTML | bytes`) — ADR 0009 permanent contract 위반 →
**거부**. Option (ii) 별도 sibling method — parallel-method maintenance surface,
모든 structural implementor 에 새 method body 강제, `@overload` 불필요 중복 →
**거부**. Option (iii) defaulted kwarg — 기존 caller (`cli.py:400`, 전체 tests) 는
`fmt` 미전달 → `bytes` (PNG) 반환, behavior byte-identical. ADR 0009 `:188` 정신
(no forced migration) 보존 → **채택**.

`@overload` variants 제공: `fmt: Literal["png"] -> bytes` / `fmt: Literal["html"] -> str`
— mypy strict 에서 기존 caller 의 narrow `bytes` type 유지.

#### D5 — Rollback flag `--static-charts` / `_STATIC_CHARTS=1`

검증 윈도우 한정 rollback path. Default = interactive. Flag 설정 시 matplotlib PNG
`<img>` fallback. ADR 0016 follow-up 에서 제거 예정 (interactive path 안정 확인 후).

#### D6 — Decimal integrity at serialization edge (P4)

`Decimal → float` 변환은 `_interactive_chart.py` 의 `_serialize_ohlcv` / `_serialize_volume` 내부 JSON-emit boundary 에서만 발생. 도메인 모델은 `Decimal` 유지.

#### D7 — Offline self-containment (P5)

`report.html` 는 network access 없이 열림. vendored JS 는 page 에 inline embed.
CDN `<script src>` zero. SHA-256 provenance: `src/research/dgt/assets/PROVENANCE.txt`.

#### D8 — `_safe_json_embed` XSS mitigation (m1)

`json.dumps(obj).replace("</", "<\\/")` — `</script>` breakout 방지.
`<script type="application/json" id="chart-data">` data island 패턴: OHLCV / volume /
marker / grid-level 데이터가 parseable JSON blob 으로 분리 — testability (m1).

#### D9 — Static 박제 path preservation + sunset trigger (R10)

Phase 0.11.h matplotlib renderers KEPT as archival-only path. Sunset trigger (R10):
matplotlib 박제 path 공식 retire 조건 — Phase 0.11.c~0.11.i 모든 retrospective
figure 가 interactive screenshot 으로 대체 완료, 또는 Phase 1 진입 후 2+ phase 에서
static figure 박제 미발생 시 (둘 중 먼저 충족되는 조건). Retire 전 별도 ADR 기록 필요.

### §1.6 Principles

- **P1** — Live interactive, static thin-for-박제. 사용자가 검토하는 모든 surface = interactive; matplotlib = archival PNG 전용.
- **P2** — Contained external dependency, user-approved. vendored JS = new dep (CLAUDE.md §0); user explicit approval + blast-radius-zero justification.
- **P3** — 5th ring isolation + intra-research directionality. Inner ring diff = 0; `visualization → dgt` ALLOWED / `dgt → visualization` FORBIDDEN.
- **P4** — Decimal integrity to serialization edge. `Decimal → float` ONLY at JSON-emit boundary.
- **P5** — Offline self-contained reports. `report.html` opens with no network access.

Phase 0.11.i 종료 직후 사용자 브라우저 확인에서 인터랙티브 차트가 **빈 화면**으로

**결함 1 — lightweight-charts v4 API / v5 lib 불일치** (`_interactive_chart.py`):
vendored JS = v5.2.0 인데 init 스크립트가 v4 API (`chart.addCandlestickSeries`,
`chart.addHistogramSeries`, `series.setMarkers`) 호출. 이 메서드들은 v5 에서 제거됨
→ 로드 즉시 `TypeError` → 차트 미렌더. 수정: v5 API (`chart.addSeries(
LightweightCharts.CandlestickSeries, …)`, `chart.addSeries(…HistogramSeries…)`,
`LightweightCharts.createSeriesMarkers(series, …)`).

**결함 2 — full-page HTML 을 `<div>` 에 raw 삽입** (`kakao_dgt_backtest.py`
`_render_html_report`): `build_interactive_chart_html` 은 완전한 HTML 문서
(`<html><head><body>`) 를 반환하는데, 이를 `<iframe>` 이 아닌 raw `<div class=
"chart-interactive">` 안에 직접 삽입했다. CSS `.chart-interactive > * { height: 100% }`
가 삽입된 `<h1>` 을 600px 로 부풀려 실제 차트(`#chart-container`)를 가시 영역 밖으로
밀어냄 — 캔버스는 정상 렌더되었으나 화면 밖에 위치. 수정: `<iframe srcdoc="…">` 삽입
(`.chart-interactive iframe` CSS 규칙이 이미 iframe 을 전제하고 있었음 — 구현 누락).

**근본 원인 — 검증 갭**: G1 검증은 구조 단언(HTML 에 `createChart`·data island·
카운트가 존재하는가) 한정으로 JS 실행/렌더링을 검증하지 않았다. 계획의 "Step 6
스크린샷 렌더 검증"은 headless 환경에서 미실행되어 HTML 직접 저장 fallback 으로
대체되었고, 그 결과 두 결함이 통과되었다. 본 phase 의 Architect R1 리뷰가 정확히
경고한 갭이다 ("`createChart` 문자열 grep ≠ 실제 렌더; 빈 차트가 통과 가능").

**재검증**: Playwright headless chromium 실제 로드 — page error 0, 캔버스 픽셀
샘플링으로 캔들·마커·거래량 렌더 확인, `.chart-interactive` 스크린샷 정상; 전체
**1650 tests PASS**, `check_namespace.sh` exit 0. 인터랙티브 figure 재생성.

**잔여 한계**: 마커 과밀 — `_build_interactive_comparison_html` 이 3개 전략 거래를
합산(~698 마커)하여 차트를 거의 덮는다. 가독성 개선은 별도 follow-up (§12.4 #6).
