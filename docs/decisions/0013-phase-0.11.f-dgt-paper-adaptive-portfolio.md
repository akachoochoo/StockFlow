### 1.4 무효화 카탈로그 (Invalidation Catalog)

#### X1. Slope/Trend 기반 k 조정 (D3)

`_DGTPaperAdaptiveRunner`의 `use_trend=True` + `_compute_slope()`:
- 선형 회귀 slope로 k 가변: 상승 → k 좁게, 하락 → k 넓게
- sensitivity 10, 15, 50, 80, 100 모두 시도
- **결과**: ATR이 이미 변동성/추세 정보 포함. slope 추가는 lagging indicator
  중복으로 과보정 발생. 모든 sensitivity에서 Hyb-Daily 대비 개선 없음 또는 악화.
- **코드 보존 이유**: `use_trend=False` (default)로 비활성 상태. 실험 재현성.

#### X2. On-Breach Rebalancing 단독 (D4)

`_DGTDynamicRunner` / `_DGTPaperAdaptiveRunner`의 `rebalance_mode="on_breach"`:
- 하락장에서 경계 이탈 → grid 재생성 → 새 grid로 매수 → 추가 하락 → 반복
- 카카오 하락장: on_breach -19.69% / MDD -22.53% (static -13.88% / -16.59% 대비 악화)
- **결론**: breach 시 재생성이 "가격 추종 매수 연쇄" 유발.

#### X3. Narrow Grid (k < 1%)

Paper-1% / Paper-0.5% 결과:
- Paper-1%: 모든 시나리오에서 Paper-3% 대비 나쁨 (과다 거래 → 비용 증가)
- Paper-0.5%: 카카오 -35.48% (최악)
- **결론**: 촘촘한 grid = 더 많은 거래 = 비용 증가 + 상승장 조기 매도.
