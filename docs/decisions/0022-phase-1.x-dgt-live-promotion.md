## 1. Context

사용자가 연구용 DGT 의 성적을 근거로 **실거래 적용**을 희망. 결정 라운드 입력 (2026-05-23 인터랙티브):

- **역할 = MDD 방어·횡보 수확** (절대 수익 추구 아님). 강세장에서 B&H 미달은 **수용**. → 연구 결론(ADR 0014 "MDD 방어 전용" / ADR 0018 regime-split)과 정합. 이 합의가 본 ADR 의 전제.
- **진행 = 결정 라운드 + ADR 부터** (구현 선행 금지).

현 상태:
- DGT 는 5th ring research overlay. inner ring (`domain/use_cases/cli/...`) 의 `from src.research.*` **FORBIDDEN** → 실거래 경로 배선 불가.
- DGT 최적 구성(memory `dgt-optimal-config`) = **일봉 daily-rebalance + ADR 변동성 + Volume Gate**, `src/research/dgt/{adaptive_runner,paper_adaptive_runner}.py`.
- Phase 1.1 실거래 인프라 머지(PR #1)됨. 단 **live 미활성** (Stage 8-7 사람 게이트) — 기존 `PriceDropStrategy` 조차 실돈 운용 전.
- 라이브 실행 모델 = cron 1일 1회, 종가 지정가, 단일 프로세스 (§10.1). → **일봉 daily-rebalance DGT 는 호환**, 분봉 DGT 는 장중 인프라 부재로 **불가**.

## 2. Decision (제안 — 결정 라운드에서 확정)

> 아래는 권고 default. 굵게 표시한 항목 중 D6/D7 은 §8 Open Questions 해소 필요.

- **D1 — 승격**: DGT(일봉 daily-rebalance, ADR+Volume Gate 구성)를 5th ring 에서 **domain strategy 로 승격**. `src/research/dgt/` 검증 로직 → `src/domain/strategies/` 정식 구현 + Port 준수.
- **D2 — 역할 박제**: DGT = **MDD 방어·횡보 수확 도구**. 강세장 B&H 미달 수용 (ADR 0014/0018 정합). 추세장 절대수익 기대 안 함 — 성공 판정 벤치마크 = "B&H 대비 MDD 개선 + risk-adjusted(Sharpe/Calmar) 비열위".
- **D3 — 분봉 제외**: 일봉 daily-rebalance 만. 분봉/틱 DGT 는 장중 인프라 없음 → 본 ADR scope 외 (§14 정합).
- **D4 — G4 불변 해제**: 본 ADR 이 inner ring 에 DGT 를 들이는 첫 결정. ADR 0007~0018 의 "inner ring 변경 zero" 는 *research phase* 룰 — 승격은 본질적으로 그 해제. 대신 **backtest↔paper 동일성(§7.4) + 기존 2265 tests 회귀 zero** 를 새 불변으로.
- **D5 — paper-first 의무**: dry-run(실시세 + Mock 체결)으로 충분 기간 검증 → MDD 방어 실증 후에야 live 게이트. 실돈 직행 금지.
- **D6 — 승격 형태 = (B) 신규 grid 패러다임** ✅ (2026-05-23 확정, §9.1). 신규 `GridStrategy` + 불변 `GridState`/`GridSlot` 도메인 모델. 기존 PriceDrop/ProfitTarget/SplitSlot/SupportSlot **0 변경**(§14 보존 invariant). dispatch = `composition.py` 문자열 분기에 `"dgt"` 추가.
- **D7 — 그리드 매도 ↔ 손절 = 알림-only 공존 + profit_guard opt-in** ✅ (§9.2). 그리드가 SELL 전권(ProfitTargetSell 미적용 — 이중 SELL 주체 충돌 회피). 손절(−20%)은 통합이 아니라 알림 레이어로 공존(§11.4 자동손절 금지 불변). `profit_guard`(평단 이하 매도 억제) opt-in, 실돈 진입 시 기본 ON.
- **D8 — universe/자본 = 저가 ETF 1종(069500) n=11** ✅ (§9.3). 절삭(holdings/(n+1)=0) 회피. 폴백 = n 축소(7~9). 자본 증액(종목당 2,500만원, ADR 0012 "소액" 위반)은 최후순위.
- **D9 — 실행 경로 = 별도 grid use_case 우회** ✅ (§9.4 Q6, Clean Architecture 우위 — 사용자 확정 2026-05-23). 근거: **SRP**(DailyOrchestrator = split-on-drop 단일 책임 / 그리드 = 별개 책임 → 별 use_case) + **OCP**(기존 Decision invariant 3 + 단일-buy 가정을 *수정*하지 않고 신규 use_case *추가* — 기존 동작 closed) + **invariant 격리**(PriceDrop 경로의 불변 보존 → G1 회귀 zero 구조적). 의존성 규칙 동일(둘 다 domain/ports inward 의존).

## 3. Drivers

- 사용자 의지 + 연구 축적 (ADR 0007~0018, 1728+ DGT tests). 단 역할이 "MDD 방어"로 한정되어 연구 결론과 모순 없음.
- 횡보/하락장 자본 보존 = 실돈 1순위 (CLAUDE.md 서두 "한 번의 버그가 돈으로 직결" 정신).
- §14 게이트가 명시적으로 본 결정 라운드를 예고 — 미룬 결정의 정식 처리.

## 4. Alternatives Considered

1. **DGT 신호만 5th ring 유지 + 사람이 수동 주문** — 자동매매 목적 미달. 단 paper 단계 전 "신호 관찰" 용도로는 유효(중간 단계 후보).
2. **B&H 정적 보유 (DGT 안 씀)** — 연구상 강세장은 이게 우위. 그러나 MDD 방어 목적엔 부적합 (B&H MDD 27~34%).
3. **PriceDrop 유지 + 일부 종목만 DGT** — 종목별 전략 차등(ADR 0021 `allow_per_asset_params` 정합). D6 형태에 따라 가능 — §8 Q3 와 연동.
4. **분봉 DGT** — 거부(D3). 장중 인프라 부재 + §10.1 단일 cron.

## 5. Why (선택 근거 — 잠정)

역할을 "MDD 방어"로 한정하면 DGT 의 구조적 약점(강세장 B&H 미달)이 *수용된 trade-off* 가 되어 연구 결론과 정합한다. research→domain 승격은 §14 가 예고한 정식 경로이며, backtest↔paper 동일성 + paper-first 로 실돈 안전성을 확보한다. G4 불변 해제는 phase 본질 차이(연구 → production 진입)로 ADR 0012 §1.6 #6 의 선례(Phase 1 = production rings 진입)와 동형.

## 6. Consequences

**Positive**:
- 횡보/하락장 자본 보존 도구 확보 (실증 시).
- DGT 연구 자산의 production 활용.

**Negative / Risk**:
- inner ring 에 grid 패러다임 진입 → 복잡도 증가 (slot 모델 분기).
- 강세장 기회비용 (B&H 미달) — D2 로 수용했으나 운영 중 체감 가능.
- 그리드 재중심 매도 ↔ 손절 상호작용 (D7) 미해소 시 평단 이하 매도 + 손실 확정 risk.
- DGT 종목당 최소 자본 ~2,500만원 제약 (memory) → 소액 운영과 충돌 가능 (§8 Q3).

### 9.1 Q1 (승격 형태) → 권고 **B (신규 grid 패러다임 + 신규 GridSlot/GridState)**

- **사실 정정**: 현 시스템에 자동 손절 없음. `StopLossPolicy`(`stop_loss.py:54-95`) = 순수 breach 감지기, live_runner는 **알림-only**(`live_runner.py:24-28,123-129`), 자동 매수차단조차 미구현.

### 9.4 신규 구조 충돌 (§8 에 추가 — 승격 전 필수 해소)
- **Q6 (HIGH) Orchestrator 통합**: `DailyOrchestrator`는 하루 0..1 BuyAction 가정 + Decision invariant 3(`buy_slot ∉ sell_slots`, `models.py:1398-1406`). 그리드는 한 bar 다수 레벨 동시 buy+sell(`paper_adaptive_runner.py:200-226`). → 그리드를 orchestrator **통합 vs 별도 use_case 우회** 결정 필요(G1 핵심 분기).

### 11.12 극단 가중 (extreme weighting) — INVALIDATE (2026-05-25)

### 11.15 극단 가중 v2 — 중심대칭 미러 (mirror) INVALIDATE (2026-05-26)

- opt-in 단일 필드 `extreme_weight_steepness: Decimal = 0` (기본 off → 회귀 zero).
- 사전 등록 게이트: 횡보 수확 ≥ baseline(cd=5) AND 하락 MDD ≤ baseline.

**백테스트 결과 (vs baseline: cd=5 / s=0)**:

**계보**: ADR 0014 H3 / 0013 D4 / §11.12 무효화와 같은 결말 — *극단에서 더 공격적
인 가중*은 DGT(자기균형 + cd로 이미 보강)에 추가 이득 없음. 사용자 직관(매도 변화
완화 + 비율 균형)은 설계상 충족하나 **PnL 게이트 미통과**. 코드 revert(inner ring
청결), 본 §11.15 정본. 무효화 카탈로그 추가: "중심대칭 미러 가중 (X) — 디자인은
대칭이나 cd 위에서 추가 이득 없음, 사용자 케이스 하락장에선 단조 악화".

### 11.16 포트폴리오 자본 효율 — `sell_cooldown_bars` 의 진짜 가치 (2026-05-27)

**발견의 출처**: 사용자가 단기 윈도 10종목 OFF/ON 비교표(`cooldown-compare_*`)를
보고 통찰 — "ON 절대수익이 낮은 건 더 적은 돈을 굴려서 그런 거 아니냐". 자본 효율
시점에서 재분석 → 가설 데이터로 입증.

**§11.13 보강** (취소 아님 — 진짜 가치의 본질 박제). 본 §11.16 이후 cooldown
운용 권고는 **"ON + N종목 분산"** 으로 갱신.

#### 단일 종목 vs 포트폴리오 (자본효율)

윈도 2025-12-02~2026-05-20 (113일), 자본 1억, 사용자 base config (n=6 on_breach
k[0.5%,2%] profit_guard).

**단일 종목 1억** (10종목 평균, cd=5 ON vs cd=0 OFF):
- ON 평균 투입금 ~28% (예수금 ~70% idle) → 절대수익 −5p(005930) ~ +13p(095660)
- 8/9종목에서 효율(PnL/평균투입) 우위지만 일부 강세장은 절대수익 양보
- → 단일 종목 단편으로는 ON 의 "강세장 양보" 통설.

**10종목 균등 분산 1억** (1천만/종목, 같은 config):

| 전략 | 최종 | 수익 | MDD | 변동성 | **Sharpe** | **Calmar** | 평균투입 | 효율 |
|------|------|------|-----|--------|-----------|------------|---------|------|
| B&H 균등 | 144.2M | +44.15% | −17.41% | 38.21% | 3.30 | 7.24 | 100% | — |
| DGT OFF | 102.2M | +2.20% | −9.87% | 19.28% | 0.26 | 0.50 | 47.1% | +4.66% |
| **DGT ON** | **104.5M** | **+4.51%** | **−4.99%** | **12.18%** | **0.85** | **2.07** | **28.9%** | **+15.62%** |

**ON 이 OFF 를 모든 지표에서 압도** (포트폴리오 차원):
- 수익 **2배** (+4.51 vs +2.20).
- MDD **절반** (−5.0 vs −9.9).
- 변동성 **63%** 수준 (12.2 vs 19.3).
- **Sharpe 3.3배** (0.85 vs 0.26).
- **Calmar 4.1배** (2.07 vs 0.50).
- 효율 **3.3배** (+15.62% vs +4.66%) — 자본 절반(28.9% vs 47.1%) 으로 더 많은 수익.

#### 본질 — idle cash 의 "분산 해방"

단일 종목 ON 의 약점(평균 70% idle cash 가 수익에 기여 안 함) 이 **분산에서 자동
소멸**. ON 의 idle 한 자본이 N종목에 걸쳐 다른 종목 수익에 참여 → 단일종목의
"강세장 양보" 가 포트폴리오 차원에서 사라진다. 동시에 cooldown 의 MDD 방어(D2)
는 그대로 유효 → 위험조정 수익 격차 확대.

→ §11.13 cooldown ACCEPT 의 진짜 가치는 *단일종목 MDD 방어* 가 아니라 *포트폴리오
자본효율*. 단일종목으로만 보면 trade-off 처럼 보이지만, 운용 시나리오(분산) 에서
**모든 차원 우위**.

#### B&H 와의 대비 (D2 정합)

B&H Sharpe 3.30 / Calmar 7.24 는 본 윈도가 강한 강세(10종목 중 7개 +90~+167%
B&H)라서. **B&H MDD −17% > ON MDD −5%** — ON 이 위험제어에서 우위. ADR 0022 D2
정합: "DGT = MDD 방어·횡보 수확 *도구*, 강세장 B&H 미달은 설계상 trade-off". ON
도 D2 trade-off 자체는 유지하나, **위험조정으로는 OFF 대비 압도적·B&H 대비 MDD
방어 명백** → 도구로서 우수.

#### 운용 권고 (갱신)

- **cooldown ON (=5)** 을 기본 운용 모드로 권고 (단일종목 운용에서도 MDD 방어 유효).
- **추가 권고: N종목 균등 분산 (≥10)** — ON 의 자본 효율을 절대수익으로 전환.
- §11.13 의 단일 종목 ACCEPT 는 유지, 본 §11.16 이 *왜* ACCEPT 인지의 본질을 박제.

#### 후속 (사용자 확정 — 2026-05-27)

다음 라운드: **분산 비율 sweep** (5/10/15종목, equal vs Kelly-가중 vs 변동성-역가중)
으로 분산 효과의 가장자리(diminishing returns) 와 최적점 탐색. 본 §11.16 의 결과는
basis (10종목·균등) 로 박제.

### 11.17 분산 비율 sweep — N과 가중 방법의 효과 (2026-05-27)

**컨텍스트**: §11.16 발견(10종목 균등 분산에서 ON 모든 차원 우위)의 가장자리 탐색.
N(종목 수)과 가중 방법(equal vs inv-vol)이 위험조정 수익에 미치는 영향 측정.

**범위 제한 (정직성 박제)**:
- N: 3/5/10 (사용자 요청 5/10/15 중 **15 미달성** — 캐시된 2025-2026 자산 10개 한정).
- 가중: equal + inv-vol(raw, capped 20%) (사용자 요청의 **Kelly 미실시** — look-ahead
  위험 + 본 라운드 범위).
- 종목 선정: 코드 정렬 첫 N (alphabetical 무작위 비포함, cherry-pick zero).
- 변동성 사전 추정: 2024-Q4(2024-10-01~12-30) 일별 수익률 표준편차 — 095660 은
  사전 데이터 없음으로 inv-vol 비교에서 **9종목 그룹**으로 한정.

#### 결과 (윈도 2025-12-02~2026-05-20, 자본 1억)

**(1) N sweep — equal weight, 코드 정렬 첫 N**

| N | cd | 수익 | MDD | Sharpe | Calmar |
|---|----|------|-----|--------|--------|
| 3 | OFF | +9.24% | −20.94% | 0.61 | 1.04 |
| 3 | ON  | +11.20% | −8.29% | 1.36 | 3.22 |
| 5 | OFF | +10.54% | −16.71% | 0.82 | 1.50 |
| **5** | **ON** | **+11.08%** | **−6.36%** | **1.67** | **4.15** ⭐ |
| 10 | OFF | +2.20% | −9.87% | 0.26 | 0.50 |
| 10 | ON  | +4.51% | **−4.99%** | 0.85 | 2.07 |

**(2) Weight sweep — N=9 (095660 제외), ON cd=5**

| 가중 | 수익 | MDD | Sharpe | Calmar |
|------|------|-----|--------|--------|
| equal | +6.04% | −5.48% | 1.05 | 2.55 |
| capped inv-vol (20%) | +5.54% | −5.53% | 1.00 | 2.31 |
| raw inv-vol | +0.20% | −0.41% | 0.63 | 1.06 ⚠️ |

#### 핵심 발견

1. **ON ⊃ OFF 보편적** — 모든 N에서 ON이 수익·MDD·Sharpe·Calmar 4개 지표 전부 우위.
   §11.16 결론(cooldown 의 portfolio 가치) 강건.
2. **N=5가 risk-adjusted sweet spot** — Sharpe 1.67 / Calmar 4.15 최고. 절대수익도
   +11.08%(N=10 의 2.5배). 종목당 2천만 자본이 cooldown+grid 활동의 최적 자본량.
3. **N=10 = MDD 최저** (−4.99%, B&H −17.4% 의 1/3.5). 종목당 1천만은 자본 비효율
   이라 수익↓ 이나 분산 효과 자체는 최대 — risk-averse 운용에 적합.
4. **N=3 = 분산 부족** — MDD −8.29% / Sharpe 1.36 (N=5 대비 열위). 변동성 제어 약함.
5. **inv-vol 가중 효과 미미** (capped 20%): equal 과 거의 동률 — 본 윈도 자산
   상관·변동성 분포로는 가중 정교화의 incremental gain 없음. **equal weight 단순함이
   충분**.
6. **raw inv-vol degenerate 위험**: 채권 ETF(214980, 저변동성)에 93.9% 몰려 거래
   거의 없음(수익 +0.20%, MDD −0.41%, 사실상 idle). **자산군 혼재 시 상한 캡 필수**.

#### 운용 권고 (3 티어, 우선순위)

| 우선순위 | 운용 모드 | Sharpe / Calmar / MDD | 근거 |
|---------|-----------|------------------------|------|
| **A. risk-adjusted 최적** | **ON cd=5 + N=5 균등 분산** | **1.67 / 4.15 / −6.4%** | sweet spot |
| B. MDD 최소화 | ON cd=5 + N=10 균등 분산 | 0.85 / 2.07 / −5.0% | B&H 의 1/3.5 |
| C. 절대수익 추구 | ON cd=5 + N=3 균등 분산 | 1.36 / 3.22 / −8.3% | N=5 와 유사하나 MDD 약간↑ |

#### 기각 카탈로그 추가

- **raw inv-vol 가중 (자산군 혼재 시)**: 저변동성 자산이 자본 독식 → 거래 무력화.
  자산군 분리 또는 ≥상한 캡 없이는 채택 불가.
- **capped inv-vol (20%, 본 윈도)**: equal 대비 incremental gain 없음 — 본 윈도
  맥락에선 단순 균등이 충분.
- **OFF cd=0 (모든 N)**: 모든 차원에서 ON 에 열위 → §11.13 ACCEPT 재확인.

#### 한계 / 후속 후보

- **N=15+ 미검증**: 추가 종목 데이터 확보 후 검증. 본 결과로 N=10 이 이미 자본
  과잉 분산을 보였으므로 N=15 는 더 악화 예측 (절대수익↓), 그러나 MDD 잠재
  추가↓ 여지.
- **Kelly 가중**: 사전 기간 mean·variance 추정에서 look-ahead 회피 설계 필요. 후속.
- **다른 윈도**: 본 윈도는 강세 풍부(B&H +44%). 횡보·약세 우세 윈도에서 N
  최적점이 달라질 수 있음 — 정상상태 권고 도출엔 멀티-윈도 sweep 필요.
- **자산군 분리 inv-vol**: 주식/ETF/채권 분리 후 각 자산군 내 inv-vol → 자산군간
  타깃 비중 — 별 ADR 라운드 영역.

### 11.18 멀티 윈도 검증 — §11.17 권고 갱신 + D2 본업 데이터 박제 (2026-05-27)

**컨텍스트**: §11.17 의 "N=5 sweet spot" 결론은 **현재 윈도(2025-12~2026-05, 강세
풍부 B&H +44%)** 단일 검증이었음. 정상상태 권고 도출엔 멀티-레짐 검증 필요 (§11.17
한계 박제 그대로). 본 §11.18 = 강세/하락/횡보/현재 4 레짐 × N=3/5/9 portfolio
sweep.

**범위 / 종목**: 9종목 (095660 제외 — 2019-2024 사전 데이터 없음). 코드 정렬 첫 N.
N=10 대신 **N=9** 채택(095660 제외 보정). 윈도: 강세(2020-03~2021-06, COVID 회복),
하락(2022-01~2022-10, 2022 베어), 횡보(2022-05~2023-06, 가장 평탄), 현재(§11.16
basis 와 동일). 모든 윈도에 9종목 데이터 검증 완료.

#### Sharpe 매트릭스 (ON cd=5)

| N | 강세 | 하락 | 횡보 | 현재 |
|---|------|------|------|------|
| 3 | 1.09 | −1.48 | 0.01 | 1.36 |
| 5 | 1.11 | −1.30 | 0.01 | **1.67** |
| **9** | **1.28** | **−0.74** | **0.20** | 1.05 |

**N=9가 4 레짐 중 3에서 Sharpe 1위** (강세·하락·횡보). N=5 의 sweet spot 은 **현재
윈도에서만** 유효 — 강세 풍부 환경의 우연.

#### ON N=9 vs B&H 9종목 균등 (레짐별)

| 레짐 | ON N=9 수익 / MDD | B&H 수익 / MDD | 결론 |
|------|-------------------|------------------|------|
| 강세 (+165%) | +9.71% / −4.37% | +164.48% / −11.62% | MDD 만 우위 (D2 정합) |
| **하락 (−11%)** | **−5.22% / −7.54%** | −10.95% / −13.77% | **모든 차원 ON 압도** ✅ |
| **횡보 (+2%)** | **+1.92% / −8.59%** | +1.70% / −13.59% | **모든 차원 ON 압도** ✅ |
| 현재 (+51%) | +6.04% / −5.48% | +50.94% / −18.06% | MDD 만 우위 |

→ **ON + N=9 분산이 하락·횡보 윈도에서 B&H 의 절대수익까지 능가** + MDD 동시 우위.
ADR 0022 D2 ("MDD 방어·횡보 수확 *도구*") 가 **데이터로 박제 입증** — 단순 trade-off
명목이 아니라 본업 영역에선 실제 능가.

#### ON vs OFF — 레짐별 (N=9)

| 레짐 | OFF 수익 / Sharpe | ON 수익 / Sharpe | ON 우위 |
|------|-------------------|--------------------|---------|
| 강세 | +21.54% / 1.49 | +9.71% / 1.28 | Sharpe·MDD (OFF 절대수익↑) |
| 하락 | −9.39% / −1.00 | −5.22% / −0.74 | **모든 차원** |
| 횡보 | +1.01% / 0.09 | +1.92% / 0.20 | **모든 차원** |
| 현재 | +5.15% / 0.61 | +6.04% / 1.05 | **모든 차원** |

OFF 는 **강세 윈도 단일에서만** 절대수익 우위 (자본 idle 없으므로). 나머지 3 레짐
에선 ON 압도. **정상상태 평균 = ON 우위**.

#### 핵심 발견

1. **§11.17 권고 A(N=5) 갱신**: N=5 sweet spot 은 강세 윈도 단일 결과 — 정상상태
   최적 아님. **N=9~10 이 정상상태**(4 레짐 평균 최우수).
2. **N=3 분산 부족 확정**: 하락 Sharpe −1.48 (N=5 −1.30, N=9 −0.74 대비 압도적 열위).
   변동성 제어 약함.
3. **ON D2 본업 데이터 박제**: ON + N=9 가 하락·횡보 윈도에서 B&H 의 절대수익까지
   능가 — 단순 trade-off 가 아닌 실제 본업 영역 우수성.
4. **단일 윈도 일반화 위험**: §11.17 의 N=5 결론이 강세 윈도 의존이었음. 멀티 레짐
   검증이 정상상태 권고 도출 필수. 이전 ADR 결론 갱신 패턴 (§11.13 → §11.16 → §11.17
   → §11.18) — 정직성 의무.

#### 운용 권고 (§11.17 갱신, 최신 권고)

| 우선순위 | 운용 모드 | 강세 알파 | 하락 방어 | 횡보 수확 | 근거 |
|---------|-----------|-----------|-----------|-----------|------|
| **A. 정상상태** | **ON cd=5 + N=9~10 균등** | 양호 | **최우수** | **최우수** | 4 레짐 Sharpe 1위 비율 최고 |
| B. 강세 알파 추구 | OFF cd=0 + N=9 균등 | +21.5% 강세 우위 | 약함 (−9% 손실) | 약함 | 강세 윈도 확신 시만 (regime timing 필요) |
| C. (구 권고 A) 보존 | ON cd=5 + N=5 균등 | "현재" Sharpe 1.67 | 보통 | 약함 | 강세 풍부 윈도 한정 |

**§11.17 의 A → C 강등 (정직성 박제). 새 A = N=9~10 정상상태**.

#### 무효화 카탈로그 추가

- **N=5 sweet spot 보편화**: 강세 윈도(2025-12~2026-05) 단일 결과 — 4 레짐 평균
  으로는 N=9 가 정상상태 우위. §11.17 → §11.18 갱신.
- **N=3 균등 분산**: 하락장 MDD −17%·Sharpe −1.48 — 분산 부족, 채택 불가.

#### 한계 / 후속

- **9종목 한정**: 095660 제외(2019-2024 데이터 없음). 다종목 풀(예: 20종목) 사용
  시 N=10/15 의 효과는 별 라운드 영역.
- **N=15+ 미검증**: 캐시 자산 부족. 분산 한계점(diminishing returns 가장자리) 정밀화 후속.
- **레짐 식별 비대칭**: 4 윈도가 결정론적 선정이나, 실시간 운용에서 *현 윈도 레짐
  식별* 은 별 도전 — regime timing 없이 정상상태(A) 권고가 안전.
- **Kelly 미실시**: §11.17 와 동일 사유.

본 §11.18 은 §11.13/§11.16/§11.17 결론을 멀티 레짐으로 검증·갱신한 *정본*.
운용 시 본 §11.18 의 권고 A 를 기본으로.

### 11.19 가격 기준 재진입 (price_based_reentry) — NUANCED (2026-05-27)

**컨텍스트**: 사용자 통찰 "ON cd=5 의 deployment 가 OFF 보다 너무 낮다. 같게 올리려면?".
cd sweep 결과 deployment ↑ ⇔ cooldown 효과 ↓ 의 본질적 trade-off 확인. *시간* 기준
대신 *가격* 기준 재진입 메커니즘으로 분리 시도.

**설계**: `price_based_reentry: bool = False` (opt-in, 기본 off → 회귀 zero).
- True 면 last_sell_price 이상에선 매수 차단. 그 아래로 떨어지면 즉시 재진입.
- sell_cooldown_bars 와 별 플래그 (둘 다 ON 이면 AND — 둘 다 통과해야 매수).
- per-asset stateful 이라 GridRunner 가 적용 (cd 와 동일 위치).
- 첫 매도 전엔 last_sell_price=0 → 게이트 비활성 (초기 매수 정상).

**구현**: domain field 1개 (`grid.py`) + runner 게이트 (`grid_runner.py`) + 5 tests
(`test_grid_runner.py::TestPriceBasedReentry`).

**4-모드 multi-window 검증** (9종목 균등, 1억, 4 레짐):

| 모드 | 강세 Sh | 하락 Sh | 횡보 Sh | 현재 Sh | **평균 Sh** | MDD 현재 |
|------|---------|---------|---------|---------|-------------|----------|
| OFF | 1.49 | −1.00 | 0.09 | 0.61 | 0.30 | −10.40% |
| cd=5 (§11.18 권고 A) | 1.28 | −0.74 | **0.20** | 1.05 | 0.45 | −5.48% |
| **price-only** | 1.52 | **−1.00** | 0.09 | 0.62 | 0.31 | −10.11% |
| **both (cd=5+price)** | **1.49** | **−0.73** | **0.20** | **1.66** | **0.65** | **−2.69%** |

**핵심 발견**:
1. **price-only ≈ OFF (3/4 윈도)**: 하락·횡보·현재에서 OFF 와 거의 동일. *price gate
   는 가격 떨어지면 즉시 풀림 = grid 의 buy trigger 와 동일 트리거 → 사실상 무력*.
   사용자 의도 (deployment ↑ + defense 유지) 중 *defense 가 미달* → **price-only =
   INVALIDATE**.
2. **both (cd=5+price) = 4 윈도 평균 Sharpe 0.65** (cd=5 단독 0.45 대비 **+44%**).
   강세·현재 윈도에서 cd=5 풀린 후에도 price gate 가 추가 차단 → MDD 더 ↓ (현재
   −5.48% → **−2.69%**, 절반). 하락·횡보에선 cd=5 와 동등 (cd 가 이미 더 strict).
3. **both = §11.18 권고 A 강화 후보**: 정상상태 운용에서 cd=5 단독보다 우수
   (4 윈도 평균). 단 *권고 A 갱신*은 이번 라운드에선 *유보* — 멀티 윈도 강건성
   추가 검증 + Kelly/regime 변형 결합 후 결정.

**판정**:
- **price_based_reentry 플래그 = ACCEPT (opt-in 보존)**. 코드 유지, 기본 off.
- **price-only 모드** (cd=0+price=True) = INVALIDATE — 무효화 카탈로그 추가.
- **both 모드** (cd=5+price=True) = NUANCED CANDIDATE — §11.18 권고 A 정상상태 갱신
  *후보* (4 윈도 평균 Sharpe +44%). 결정 보류.

**무효화 카탈로그 추가**: price-based reentry 단독 (cd 없이) — 하락/횡보 윈도서
defensive 효과 zero (OFF 와 동등).

**한계 / 후속**: 멀티 윈도 4개 모두 9종목 동일 구성 — 종목 풀 변경 시 robust 한지
미검증. Kelly 등 가중 변형과의 결합 효과 별도. *both* 의 권고 A 정식 갱신은 추가
검증 라운드 영역.

### 11.20 외곽 가중 v3 — i/n on cd=5 INVALIDATE (2026-05-27)

**컨텍스트**: 사용자 제안 — "단순하게 ON 에서 그리드 외곽으로 갈수록 매수/매도 수량
좀 더 늘리기". §11.12 (i/n 비대칭) 와 §11.15 (중심대칭 미러) 의 후속 미검증 빈칸:
**i/n on cd=5** 조합. §11.12 는 cooldown 도입 전 검증, §11.15 는 미러형 (다른 디자인).
i/n × cd=5 직접 조합은 데이터 빈칸 → 데이터로 확정.

**테스트 방식 (monkey-patch, 도메인 코드 무변경)**: GridStrategy._sell_decision /
_buy_decision 을 monkey-patch 로 i/n 가중 임시 적용 (w_sell = 1 + s·(i/n),
w_buy = 1 + s·((n-i)/n)). 각 s 시도 후 원본 복원. 16 backtests = 4 윈도 × 4 s 값
({0.1, 0.2, 0.3, 0.5}) + s=0 baseline.

**결과 (4 윈도 평균 Sharpe)**:

| s | 강세 | 하락 | 횡보 | 현재 | **평균** |
|---|------|------|------|------|----------|
| **0 (baseline cd=5)** | 1.28 | −0.74 | 0.20 | 1.05 | **0.448** ⭐ |
| 0.1 | 1.41 | −0.83 | 0.20 | 0.98 | 0.440 |
| 0.2 | 1.18 | −0.90 | 0.17 | 1.21 | 0.415 |
| 0.3 | 1.23 | −0.91 | 0.16 | 1.10 | 0.395 |
| 0.5 | 1.12 | −0.90 | 0.15 | 0.80 | 0.293 |

**baseline (s=0) 가 평균 Sharpe 최고**. 어느 s 도 baseline 을 의미 있게 능가 못 함.

**결정적 발견 — 하락장 단조 악화** (예측 메커니즘 데이터로 확정):

| s | 하락 Δ수익 | ΔMDD |
|---|------------|------|
| 0.1 | −0.86p | −0.87p |
| 0.2 | −1.60p | −1.50p |
| 0.3 | −1.71p | −1.63p |
| 0.5 | **−1.86p** | **−1.81p** |

**완벽한 단조 악화 패턴**. 메커니즘: **하단 매수 가중↑** = cd 풀린 후 더 큰 매수 발동
→ "하락 재매수 연쇄" 가속 → MDD 악화 + 수익 악화. 사용자가 cooldown 으로 막으려던
바로 그 패턴을 외곽 가중이 정확히 증폭. 사용자 의도 (방어 강화) 와 *정반대*.

**다른 윈도 — 미세하고 비일관**: 강세 s=0.1 만 약 우위 (Sharpe +0.13), 다른 s 는
노이즈. 횡보·현재 s↑ 따라 미세 악화 또는 비단조 (s=0.2 가 현재 windows 에서만 우위).

**판정 = INVALIDATE (외곽 가중 3번째)**:

| ADR | 형태 | 조합 | 결과 |
|-----|------|------|------|
| §11.12 | i/n 비대칭 | cd 없음 (도입 전) | INVALIDATE |
| §11.15 | 중심대칭 미러 | cd=5 위에서 | INVALIDATE |
| **§11.20 (이번)** | i/n 비대칭 | **cd=5 위에서** | **INVALIDATE** |

**구조적 종결**: 세 변형 모두 동일 메커니즘으로 기각. cd=5 가 이미 MDD 방어를 차지한
상태에서 외곽 가중은 추가 여지를 만들지 못함. 특히 하단 매수 가중은 cd 의 의도와
정면 충돌. **외곽 가중 카테고리 전체에 대한 결정적 데이터 박제** — 누군가 동류 시도
시 본 §11.12 + §11.15 + §11.20 3중 무효화를 즉시 인용.

**무효화 카탈로그 추가**: i/n 외곽 가중 on cd=5 — 하락장 단조 악화 (메커니즘:
하단 매수 증폭 = 재매수 연쇄 가속).

**테스트 방식 메타**: 도메인 코드 손대지 않고 monkey-patch 로 검증 완료. 본 결과로
i/n 코드 영구 추가 불필요 — 이미 §11.12 박제와 동치 결론 확장.

### 11.21 both 모드 정식 채택 — §11.18 권고 A 갱신 ACCEPT (2026-05-27)

3. **MDD 방어 (D2 본업) 4/4 유지**: 모든 윈도에서 DGT MDD < B&H MDD (강세
   −17 vs −28 / 하락 −8 vs −16 / 횡보 −8 vs −12 / 현재 −6 vs −17). 종목 풀
   확장에도 D2 정합 깨지지 않음 — 분산이 MDD 만큼은 도와준다는 사실 확인.
4. **현재 윈도 회귀 가장 큼**: §11.21 N=9 Sharpe 1.66 → N=15 0.58 (−65%).
   강세 풍부 환경에서 N=15 자본 분산이 grid 알파를 가장 크게 희석.

#### 판정 = INVALIDATE (N=9~10 sweet spot 유지)

| 기준 | 결과 |
|------|------|
| N=15 절대수익 우위 | ❌ 4/4 윈도에서 N=9 대비 절대수익 ↓ |
| Risk-adjusted (Sharpe) | ❌ 평균 −52%, 3/4 윈도 열위 |
| MDD 방어 강화 | ✅ B&H 대비 우위 유지 (단 N=9 보다 개선 없음) |
| 자본 효율 | ❌ 종목당 자본 부족 → 고가주 grid 활동 제약 |

→ **§11.18·§11.21 권고 A (N=9~10 균등) 갱신 불필요. N=15 sweet spot 가설 기각**.

#### 갱신 카탈로그

- **무효화 신규 (§11.22)**: N=15 균등 분산 — 정상상태 4 윈도 평균 Sharpe N=9

  보편화 무효화와 동형 (N 의 양 끝 모두 sub-optimal, sweet spot = N=9~10).
- 권고 A 변경 없음 (§11.21 유지).

#### §11.18·§11.21 한계 CLOSED

- ~~"N=15+ 미검증 — 종목 풀 확장 후"~~ → **§11.22 데이터로 검증 완료**.

§12.3 D20 권고 A 정식 박제. partial fill 차단이 **grid 주문에도 동일 적용**.

- **현행 상태**: `MockBroker.__init__` 에서 `simulate_partial_fill_rate != 0.0` 거부 (`broker.py:72-77`). ADR 0002 §3.2.1 + 본 §12 D20 정합.
- **Grid 적용 근거**: D18 (`OrderRequest.slot_number XOR grid_level_idx`) 보장 — 동일 OrderRequest 가 split 든 grid 든, partial fill 정책은 단일. MockBroker 의 `_apply_grid_buy_fill`/`_apply_grid_sell_fill` 도 full fill 가정 (D19 commit `a80441f`).
- **Backtest 이상화**: GridRunner = full-fill-at-close 이상화 (`grid_runner.py:14-15`). G2 진성 동등성 (D23) = dry-run MockBroker (full fill 강제) ↔ GridRunner 비교.
- **KIS live partial fill 처리**: 실거래 KIS 가 partial fill 반환 시:
  1. broker.get_order_status → PARTIALLY_FILLED
  2. PendingSettler 가 `_NON_TERMINAL` 으로 분류 → 다음 cron 까지 대기
  3. 다음 cron 에서 terminal (FILLED / CANCELED / EXPIRED) 확인 후 처리
  4. reconciliation (asset_code aggregate 대조, `reconciler.py:150-170`) 가 누락 흡수 — slot 무관이므로 grid 에도 유효.
  5. 1 영업일 초과 PENDING/PARTIALLY_FILLED 잔류 시 `StateMismatchError` halt (gap b, `pending_settler.py:354-369`).
- **변경 zero**: D20 박제로 코드 추가/수정 없음. broker.py 주석에 ADR 0022 §12 D20 인용만 추가 (commit 본 박제와 함께).
